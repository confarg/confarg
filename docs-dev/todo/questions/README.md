# Questions

Points only the maintainer can settle: missing rationale, undecided trade-offs, anything where
guessing would bake in a choice nobody made. Ask, then record the answer in
[../../architecture/](../../architecture/README.md) and delete the file.

One ticket per file, named `Q-<n>-<slug>.md`; see [../README.md](../README.md) for the format.
Questions carry no effort, risk or impact — a question is answered, not implemented.
