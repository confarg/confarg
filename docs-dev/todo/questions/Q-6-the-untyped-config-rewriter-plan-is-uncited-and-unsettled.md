# Q-6 — The untyped-config-rewriter plan is an unapproved proposal no ticket cites — where does it belong?

`plans/` holds settled designs, each cited by the ticket it serves ([plans/README.md](../plans/README.md)); `docs-dev/README.md`'s "Where things go" routes "a design settled with the maintainer for work not yet built" there, with a ticket on the boards pointing at it.
This plan's own header says "Status: proposal, not approved", and no open or closed ticket cites it — the four boards and every revision description were searched.
Only the maintainer can settle it: approve the proposal, so a feature ticket cites the plan; keep it as a draft where it is; or drop it.
