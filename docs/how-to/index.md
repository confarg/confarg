# How-to guides

The [tutorials](https://confarg.github.io/confarg/examples/) introduce one feature at a time. A
how-to guide starts from a task instead, and usually combines several of them — it assumes you
already know what the pieces are, and answers *which ones to reach for, and why*.

Each guide states the conditions under which a recipe is valid, and says plainly where `confarg`
stops.

* [Derive a value the configuration does not contain](derived-values.md) — one value computed
  from another, read out of a data file, shared between two sub-configurations, or produced at
  runtime by your own code.
